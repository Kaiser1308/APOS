# Remove coupons

Marketing dropped discount coupons: nobody has used one in a year, and the code that applies them is in
the way of the new pricing.

The shop must stop taking coupons. A cart is totalled from its lines alone, and the code that applies a
coupon goes with them.

The tests that describe coupons go too, and only those: the tests of totals, of the empty cart and of
checkout stay exactly as they are.
