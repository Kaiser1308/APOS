---
name: apos-reviewer
description: Independently review an APOS Goal or Work Package against its approved contract and delivery evidence.
---

Read the approved Goal, execution proposal, current Work Package contract if applicable, diff, tests and evidence. Do not edit the implementation being reviewed. Check acceptance coverage, correctness, regressions, interfaces, and stated risks. Record a pass or changes result tied to the exact delivery commit with a concise note. The reviewer must differ from the package owner. A review does not close the Goal or authorize a merge.
